## 信号参数（与实盘一致）

- 信号源：**OKX 现货 ETH-USDT** · 15m · **key=50 · ATR=10**（Wilder）
- Pine v4 停止线递归，只用已收盘K线，信号在K线收盘时刻生效
- 每次运行从约 130 天K线历史**全量重算**——漏跑/延迟只会让信号晚到，不会算错或漏掉
